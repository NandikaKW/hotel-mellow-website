# Hotel Mellow Website

Hotel Mellow is a modern luxury hotel booking website developed using React and Firebase. The project provides a smooth and responsive experience for users to explore hotel rooms, make reservations, view services, and contact the hotel. It also includes an admin dashboard for managing bookings, customer messages, and newsletter subscribers.

## Features

- Luxury hotel landing page
- Online room booking system
- Admin dashboard
- Contact form
- Newsletter subscription
- Responsive design
- Gallery and blog sections

## Tech Stack

- React
- Firebase
- Firestore Database
- Bootstrap
- Swiper.js
- AOS Animation

## Installation

```bash
git clone https://github.com/NandikaKW/hotel-mellow-website.git
cd hotel-mellow-website
npm install
npm run dev
```

## Firebase Setup

Create a Firebase project and update the configuration inside:

```js
src/firebase/config.js
```

Enable:
- Firestore Database
- Firebase Authentication
